## Чекліст для завершення перевірки поза локальним середовищем

1. У Chrome, Firefox і Edge окремо пройти реєстрацію → вхід → створення
   HTTP/HTTPS-адреси → відкриття короткого URL → перегляд лічильника →
   видалення → вихід. Перевірити помилки URL та мобільну ширину сторінки.
2. На реальному сервері з TLS перевірити `http://` → `https://`, прапорці
   Secure у cookie, домен, `manage.py check --deploy`, захист заголовка проксі.
3. Зберегти посилання, перезапустити сервер, перевірити, що воно відкривається;
   зробити резервну копію БД і тестове відновлення. Повторити навантажувальний
   замір у контрольованому середовищі, не запускаючи локальний скрипт проти
   production (він змінює БД).

Пункти 1–3 не позначено як виконані: відсутні результати відповідних прогонів.
